Tree

Description: A hierarchical data structure consisting of nodes, with one root node and child nodes. Example Use: Representing hierarchical relationships like organization charts or file systems.


            
Binary Tree:
Description: A tree where each node has at most two children.

                Example Use: Used in binary search algorithms and expression trees.

            
Binary Search Tree (BST):
Description: A binary tree where the left child contains elements smaller than the parent, and the right child contains elements larger.

                Example Use: Fast searching, insertion, and deletion operations.

                
                
            
Heap:
Description: A binary tree with a special property: the parent node is either greater than (Max-Heap) or less than (Min-Heap) its children.

                Example Use: Efficiently implementing priority queues.

            
Graph:
Description: A collection of nodes (vertices) connected by edges.

                Example Use: Social networks, route maps, and dependency trees.
